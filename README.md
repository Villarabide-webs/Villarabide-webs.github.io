# Portfolio de Noel Villarabide

Webs para negocios locales: restaurantes, peluquerías, clínicas y talleres.

Web publicada: https://villarabide-webs.github.io

## Estructura

- `index.html`: página principal del portfolio.
- `demos/salitre/`: restaurante, con carta por pestañas y reserva de mesa.
- `demos/navalla/`: barbería, con reserva de cita por horas.
- `demos/marea/`: fisioterapia, con mapa del cuerpo interactivo.
- `demos/albura/`: carpintería tradicional, con formulario de presupuesto.
- `demos/veta/`: ebanistería, con selector de madera.
- `demos/encaje/`: cocinas y armarios, con calculadora de precio.

Todo es HTML, CSS y JavaScript sin dependencias. Las demos son negocios ficticios.
